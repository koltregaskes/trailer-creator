# Setup

1. Open `index.html` in a modern browser. Opening the file directly is the supported route. No local server is required for editing, the delivery checklist, or export.
2. If the browser can read the adjacent `.txt` files, the page will load them directly as the starting draft.
3. If local file access blocks those reads, the page falls back to bundled content so editing and export still work offline.
4. After that, edits are stored locally in the browser until you reset or import a different draft.
